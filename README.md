# OmaValet

OmaValet parks startup apps in the Omarchy workspaces where they belong.

> Early development build for Omarchy Quattro. Installation instructions will be added after live validation.

## Design

- Pick applications by their desktop name and icon.
- See existing workspace assignments before making changes.
- Keep user-authored `autostart.lua` and `hyprland.lua` content intact.
- Match Omarchy's current theme without a separate visual skin.
